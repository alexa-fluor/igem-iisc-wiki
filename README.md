# MOSKATEER wiki — the whole site

One runnable React 19 + Vite + TypeScript project carrying every page of the
wiki. Built from the team's write-ups in the Google Doc, in the layout the four
pages written earlier established.

```
npm install
npm run dev        # http://localhost:5173
npm run build      # type-checks, then writes dist/
IGEM_BASE=/iisc-bengaluru/ npm run build   # for the live wiki
```

## Layout

```
index.html                 the single page the SPA is served from
vite.config.ts             base path for iGEM's sub-path hosting
public/
  fonts/                   self-hosted Inter, Noto Sans, Onest, Amatic SC
  files/pMOSK1_annotated.gb the annotated plasmid, linked from the Parts page
src/
  main.tsx                 React root, router basename, stylesheet order
  App.tsx                  one <Route> per entry in pages.ts
  pages.ts                 THE page registry: navbar, routes, footer, prev/next
  global.css               webfonts, type scale, site tokens, reset
  components/
    Layout.tsx             navbar + footer chrome (no page header: pages draw their own)
    WikiPage.tsx           the shared page shell + P, H3, List, Pull, Note, Cards, Steps, Table
    wiki-page.css          hero, sticky navigator, bands, content pieces, breakpoints
    LowPoly.tsx            the faceted canvas backdrop, shared by every hero
    Figure.tsx             inlines a generated SVG and draws its strokes on scroll
    Md.tsx                 small Markdown renderer for the write-ups
    NotFound.tsx
  hooks/
    useScrollReveal.ts     one IntersectionObserver per page for [data-reveal]
    useSectionProgress.ts  active section + progress, measured in a rAF
    useReducedMotion.ts
  contents/
    home|ideation|education|sustainability.(tsx|css)   the four hand-built pages, unchanged
    description|design|engineering|experiments|results|model|parts|safety.tsx
    human-practices|communication|team|attributions.tsx
    writeups/*.md          the team's own prose, rendered verbatim by Md.tsx
  assets/figures/*.svg     generated by wiki/illustrations/_source/build.py
```

## Adding or changing a page

1. Write `src/contents/<page>.tsx` exporting a component. Long prose goes in
   `src/contents/writeups/<page>.md` and is rendered with `<Md source={...} />`,
   so editing the text never means editing JSX.
2. Add it to `PAGES` in `src/pages.ts`. The navbar, the routes, the footer
   sitemap and the previous/next links all read from that one array.

Most pages are built from `WikiPage`, which gives the faceted hero, the sticky
section navigator on the left and the alternating bands. Home, Ideation,
Education and Sustainability are hand-built instead, because each has its own
scroll choreography; they are carried across unchanged and keep their own CSS.

## Figures

Never edited by hand. They come from the project's illustration system:

```
cd ../illustrations/_source && python3 build.py
cp ../svg/*.svg ../site/src/assets/figures/
```

`STYLE-GUIDE.md` next to that script is the contract: palette, stroke weights,
shape language, arrow semantics, label blocks. A new figure is a function in
`figures.py` added to `ALL`, not a hand-drawn file.

## Type

Fixed across the site, in `global.css`:

- Headings — Inter 700, `font-feature-settings: "cv11" 1, "ss01" 1`
- Running text — `"Segoe UI", "Noto Sans", system-ui, -apple-system, sans-serif`,
  400, `clamp(17px, 1.6vw + 1px, 24px)` / 1.5
- Secondary text — 0.8em of running text, same line-height

Segoe UI is a Windows system font and cannot be redistributed, so Windows
readers see Segoe UI and everyone else sees Noto Sans. That is intended.

## iGEM constraints

No CDN links anywhere: fonts are self-hosted, figures are inline SVG with no
external references, and the only runtime dependencies are React, react-router
and Bootstrap, all bundled. Set `IGEM_BASE` at build time so the router and the
asset URLs match the team's sub-path, and upload `public/fonts/` to
static.igem.wiki, pointing the four `@font-face` rules at it.
